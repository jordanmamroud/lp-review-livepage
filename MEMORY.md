# Lessons learned in this repo

Rules future work must follow. Each has why, the date, and where it came from.

**Name files so the name says what they are, in plain words.** Any file a run reads and follows is `run-instructions.md`, and its folder says which run (`src/` for the review, `tests/<what-it-tests>/` for a test). No vague names like `steps.md` or `extra.md`.
Why: Nov 12, 2026. Jordan couldn't tell what `steps.md` was for, and `scheduled-task.md` sounded like a timer. (Jordan, in chat; ADR 0005)
